# Decollaboration / One Thread at a Time / 三人行

**Shared thread:** every conversation a researcher has with an AI instead of a colleague pulls one
thread out of the research community's web (inspired by Daniel Hook, "The Waymo effect"); the AI
only critiques what you ask, so the flaws you never raise stay hidden.

## How the two versions differ

| | en: One Thread at a Time | zh: 三人行 |
|---|---|---|
| Title / frame | a thread pulled at a time | 《论语》"三人行，必有我师焉" |
| Characters | Researcher, Colleague A (mug), B (scarf) | 研究生, 师兄 (保温杯), 师姐 (pencil bun) |
| Setting | a round table | 组会 round table |
| Why switch to AI | "No arguments. No credit disputes." | 不欠人情，也不挨怼 |
| The turn | "So productive!" | "效率拉满！" |
| The caption | "They just stopped asking one another." | 三人行必有我师，可谁都不问谁了 |

Kept identical because culture-neutral: the claim, the four-beat structure with the 1↔3 / 2↔4
mirror, the orange threads and spools, the empty chair, and the punchline's limit on AI critique.
