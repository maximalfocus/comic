# What Is DNS For?

**Shared thread:** Terence Eden's argument that, judged by what it actually does — 85M new gTLD
registrations in 2025, 10%+ blocklisted, perhaps 1 in 5 scams — the Domain Name System looks like
a machine for running scams (the purpose of a system is what it does).

## Versions

- en: What Is DNS For? — a registrar-counter allegory, 2×2 (`en/substack-post.md`).
- zh: 域名在给谁指路？ — a culturally adapted Chinese version (not a translation), converged via a
  Claude+Codex peerreview brainstorm (8 rounds). Rendered as a 小红书 vertical 1×4 strip. The
  registrar counter was rebuilt into a native **crossroads / signpost** metaphor: a 路牌师傅 hands
  a shop a sign ("一分钟全网找到你"), scammers order fake「官方客服 →」signs that lure a passerby
  into a skull alley, the overview shows「约1/5涉诈（估）」, and 实名/押金/审核 gate the honest
  person while a scammer gets a sign at 另一个路口.

## How the two versions differ

| | en: What Is DNS For? | zh: 域名在给谁指路？ |
|---|---|---|
| Metaphor | a registrar service counter | signposts at a crossroads (DNS points names to places) |
| Scam surface | UK gov.uk-dwpaph.bond spoofs | 冒充「官方客服」的假路牌，钓走路人（native 被钓鱼 image）|
| Friction | ID / €900 deposit / Monday | 实名 / 押金 / 等审核 |
| Layout | 2×2 grid, 4:3 (Substack) | vertical 1×4 strip, 9:16 (小红书) |
