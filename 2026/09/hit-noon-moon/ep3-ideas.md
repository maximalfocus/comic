# 哈工大人的中秋 · 第三集创意

素材：《中秋午宴节目流程》v3 与《筹备工作组会议纪要》9.14 v5（原件不入库）。漫画只用角色
（工科校友、学长、学生、主持人），不出现真实姓名、嘉宾、收款信息或座位。

延续：戴眼镜的工科校友、橙色强调色、中文竖版四格。

## 方案 A（推荐，第3版）：博饼状元

素材：13:15–13:40 各桌博饼；13:40 上最后一道甜品；奖品清单里有「大模型 token API 额度
20 美元」。博饼规矩：状元可被之后掷出的更大状元抢走，「状元插金花」（四个红四 + 两个一）最大。

| 格 | 画面 | 台词 |
|---|---|---|
| 1 起 | 角标「13:15 博饼」。工科校友第一把就掷出四个红四（橙），举着奖品卡「大模型token 20美元」（橙），推眼镜。 | 「状元。按规矩，只有更大的才能抢走。」 |
| 2 承 | 角标「13:39 最后一把」。最后一人掷完，什么也没有；工科校友靠回椅背，搂着奖品卡。 | 「状元，稳了。」 |
| 3 转 | 角标「13:40 上甜品」。服务员伸手端走博饼大碗腾位置，骰子在碗里一晃——停成四个红四加两个一（橙）。全桌定格。 | 「……状元插金花。」 |
| 4 合 | 服务员端着碗、拿走奖品卡离开；工科校友扑过去。 | 「那是万分之三！」服务员：「按规矩，我收了。」 |

说明：月圆人团圆，状元归服务员。

转折在哪里（第3格）：第1格他亲口立下的规矩，是埋好的雷；最后一把过去、他宣布「稳了」，
读者以为故事结束。然后一个根本没在玩的人，收碗时无意一晃，晃出了最大的状元。

笑点在哪里（第4格）：
1. 他的规矩反过来咬了他：「按规矩」是他第1格的原话，被服务员拿去用。
2. 他到最后还在报概率：输了第一反应不是生气，是「万分之三」——人设坚持到底。
3. 系列梗：第二集服务员端走了蛋黄，这集端走了状元；说明文字也对仗第二集
   「蛋黄归服务员」。服务员成为全系列的真正赢家，第四集可以继续升级。

不看第二集也成立：第1格已交代规矩，读者不懂博饼也看得出「更大的状元抢走了」。

数字核对：插金花 = 四个4 + 两个1，15/46656 ≈ 0.032%，即「万分之三」。

## 被替换的方案 A 第2版（供对照）

素材：13:15 各桌博饼；奖品清单里有「大模型 token API 额度 20 美元」。

| 格 | 画面 | 台词 |
|---|---|---|
| 1 起 | 角标「13:15 博饼」。全桌热闹摇碗，工科校友抱臂坐着，面前一台计算器。 | 「状元概率1.2%，期望值两毛四。不玩。」 |
| 2 承 | 旁人把碗推给他；他勉强一掷——碗里四个红四（橙）。全桌跳起来，递上奖品卡「大模型token 20美元」（橙）。 | 「就一把嘛。」「状元！！」 |
| 3 转 | 角标「第99把」。工科校友袖子撸起、眼镜歪斜、双手抱碗狂摇，全桌往后躲。 | 「再来一把！就一把！」 |
| 4 合 | 散场后的空桌边，他低头看手机，用赢来的 token 问 AI；手机弹出回复气泡。 | 「AI，怎么戒博饼？」「建议先算一下期望值。」 |

说明：规格严格，功夫到家，博饼除外。

笑点（每格一个，最后一个最响）：
1. 人设：别人在玩，他在算期望值（1.2% × 20美元 = 0.24美元），理性到扫兴。
2. 打脸：唯一不想玩的人，一把就中了状元。
3. 反转：全桌最理性的人，成了全场最上头的人。「就一把」从别人劝他，变成他求自己——
   同一句话，主语换了。
4. 回收：他用赢来的 AI 额度求助，AI 把第1格他自己的话原样还给他。读者不用推理，一眼看到
   「期望值」三个字就懂。

安全：不涉及真实人物、致辞嘉宾或学术诚信；「上头」是自嘲，不是讽刺活动。

数字核对：6 颗骰子，四红及以上、五子、六子合计 561/46656 ≈ 1.2%；0.012 × 20 = 0.24。

替换原因：没有真正的转折。第1格「不玩」一出，读者已预见他会上头；第4格只是回到第1格的
期望值，是闭环不是意外。

## 被替换的方案 A 初版（供对照）

1. 工科校友：「状元概率才1%，随便掷。」 2. 在校学生一把掷出状元。 3. 学生拿 token：
「正好，拿去写毕业论文。」 4. 学长们一拥而上：「学弟，我的致辞稿也拜托了！」

替换原因：第1–2格是铺垫、无意外；学术诚信梗在校友圈有风险；「致辞稿」暗示致辞人用 AI 写稿，
与方案 C 同样可能被对号入座；工科校友只铺垫、没有自己的反转。

## 方案 B：称谓改革

素材：纪要写明「应朱学长建议，自本纪要起不加学长/学姐称谓」——提议取消「学长」称谓的
那句话里，就用了「学长」。

| 格 | 画面 | 台词 |
|---|---|---|
| 1 起 | 角标「周一 21:30 工作组会议」。一人举手提议，全体举手。 | 「提议：以后不叫学长学姐。」「同意！」 |
| 2 承 | 角标「23:30」。有人熬夜敲纪要，屏幕发光。 | 「纪要v5，发群。」 |
| 3 转 | 特写纪要一行：「应朱学长建议，不加学长称谓。」「学长」两字用橙色圈出。 | （无台词，或提议人：「……」） |
| 4 合 | 微信群刷屏：一排一模一样的回复气泡。 | 「收到，朱学长。」×4 |

说明：称谓改革，第一天就失败了。

笑点：文件自己打自己脸（真实发生），第4格群里「收到」接龙人人见过。呼应第二集「学长您先请！」。

风险：「朱学长」是真实的人（很可能就是你）。公开发布可改成「某学长」，笑点不变；只发工作群
则保留原样更好笑。

## 方案 C：以现场为准

素材：流程表精确到每道菜 15 分钟、每人致辞 4–5 分钟；纪要 9 页、流程 v3；每页页脚都写着
「具体时间以现场为准」「以工作群最终确认为准」。

| 格 | 画面 | 台词 |
|---|---|---|
| 1 起 | 工科校友捧着厚厚一沓流程表 v3，表格密密麻麻。 | 「每道菜15分钟，误差±1。」 |
| 2 承 | 角标「12:00」。台上致辞人举着话筒，冷盘刚上桌。 | 「我简单说两句。」 |
| 3 转 | 角标「12:40」。冷盘盘子已空，汤也凉了；致辞人还在讲。 | 「最后，我再强调三点。」 |
| 4 合 | 工科校友翻到流程表最底下，指着页脚那行小字（橙色）。 | 「原来最重要的一行，在页脚。」 |

说明：规格严格，以现场为准。

笑点：「简单说两句」「最后再强调三点」是国民级梗；页脚那行字是真实文件里的，精确计划被一
行免责声明整体作废。

风险：当天致辞的是会长和大使馆公参，哪怕角色匿名也可能被对号入座。只建议在活动后、且确认
主办方不介意时用。
